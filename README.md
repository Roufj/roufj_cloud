# Game Publishing BI Dashboard · DEMO v4

실제 기업 및 게임의 운영 실적과 무관한 **가상 데이터 시뮬레이션** 대시보드입니다. 데이터 종료일은 **2026-10-31**입니다.

## Windows PowerShell 실행

압축을 해제하고 `app.py`가 있는 폴더에서 다음 명령을 실행합니다.

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

기존 버전 실행 중이면 해당 터미널에서 `Ctrl+C`로 먼저 종료합니다. `http://localhost:8501`로 접속합니다.

## v4 주요 변경

- 라이트/다크 테마에서 읽기 쉬운 테마 기반 KPI 카드 및 DEMO 안내 배너
- 날짜 직접 선택, **30일 이하 일별 / 31일 이상 월별 자동 집계**, 일별·월별 수동 선택
- 매출·DAU·CS 시계열에 **TOTAL 통합선** 및 프로젝트별 선 표시 (전체 프로젝트 선택 시)
- 리텐션에 코호트 규모 기준 TOTAL 가중선 표시
- **선택 기간** 목표 매출, 실적, 사업이익, 달성률 표시 및 프로젝트별 상세
- 장르별 지난 3개월 실적과 사전 이벤트 계획에 따른 월별 목표 생성; 목표 사업이익은 목표 매출의 15%
- 월중 시점 기준 월말 예상 매출·사업이익 표시; 이후 데이터 미사용
- 사업 상세의 **부분 월 일별 손익 배분** 및 별도 월간 원본 정산표
- 표와 다운로드 파일의 한글 항목명, 금액 천 단위 쉼표
- 공식 운영 사이트 링크 및 가상 데이터 표시가 포함된 CSV 추출

## 데이터와 정산 기준

- A: MMORPG / 2021-10-27 출시 / MG 5억 / RS 20%
- B: SLG / 2024-07-24 출시 / MG 3억 / RS 18%
- C: Puzzle / 2026-01-28 출시 / MG 5천만 / RS 25%, IAP + IAA
- RS 산정 기준: IAP + IAA 순정산액 - 환불 - 마켓 수수료
- 사업이익: 순매출 - 발생 RS - 서버비 - 운영비 - UA 집행비
- MG 선지급 및 상계는 사업이익에서 중복 차감하지 않습니다.
- 부분 기간의 고정비는 프로젝트별 해당 월 서비스 일수로 나누어 배분한 **사업관리용 추정**입니다. 월간 정산 원본은 별도 표로 제공합니다.
- 프로젝트별 DAU 합계는 게임 간 중복 제거된 고유 이용자 수가 아닙니다.
- 코호트, MAU, MPU는 합성 집계로 원천 유저 ID 이벤트 기록을 제공하지 않습니다.
- API 연결, 자동 스케줄러, 실제 AI 모델 호출은 포함되지 않습니다.

`generate_data.py`는 동일한 가상 원본 데이터를 재생성하는 스크립트입니다. ZIP에는 이미 데이터가 포함되어 있어 실행할 필요가 없습니다.
